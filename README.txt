Веб-сайт "Audio Player" (опционально V3.00). Веб-сайт ориентированный на проигрывание треков, которые находятся в секции библиотеки, что получаются из сервера по API связке. 

Основной стек:
• HTML5 (язык гипертекстовой разметки)
• БЭМ (методология именования классов)
• CSS3 (каскадные таблицы стилей)
• SCSS (препроцессор SASS)
• JS (язык программирования)
• NodeJS (серверный JS)
• jsmediatags (библиотека JS для обработки файлов .mp3)
• express (библиотека JS для раскрытия сервера)

Присутствие на сайте:
• Header (логотип; навигация; кнопки регистрации и авторизации)
• Main (четыре секции)
• Aside (панель продвижения; настройки)
• Footer (логотип; контакты; конфиденциальность; изображение)

Механики:
• Плавный переход точек перехода
• Использования neon-стилей
• Светлая и тёмная тема
• Добавление треков через сервер
